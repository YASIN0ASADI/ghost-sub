# پیش‌نمایش تم بنفش و گرفتن اسکرین‌شات

تم چهارم با پس‌زمینهٔ تیرهٔ بنفش، تأکید یاسی `#b78bff` و گرادیان روشن‌تر طراحی شده است. رنگ‌های وضعیت موفق/ناموفق معنای قبلی را دارند. دکمهٔ رنگ پس از آبی به بنفش و سپس قرمز می‌رود.

## انتخاب در نصب واقعی

۱. دستور تک‌خطی README را روی سرور پنل اجرا کنید تا نسخهٔ منتشرشده دریافت شود.
۲. گزینهٔ `1` برای نصب اولیه یا `2` برای تغییر ظاهر را بزنید.
۳. پنل را انتخاب کنید؛ در `Default theme` عدد `4` را وارد کنید.
۴. خلاصه را بررسی و اعمال را تأیید کنید؛ لینک اصلی ساب را بدون کش تازه کنید.

برای حفظ رنگ فعلی در نصب‌های بعدی Enter بزنید. رنگ ذخیره‌شدهٔ بنفش، برند، عکس و تنظیمات نمودارها حفظ می‌شوند.

## پیش‌نمایش امن روی کامپیوتر

از ریشهٔ پروژه در PowerShell ویندوز:

```powershell
py scripts/build_preview.py
Start-Process .\preview\sub-purple.html
```

برای دو پنل دیگر، فایل `preview/marzban-purple.html` یا `preview/pasarguard-purple.html` را باز کنید. ۱۲ ترکیبِ سه پنل و چهار رنگ تولید می‌شود. همهٔ اطلاعات و لینک‌ها ساختگی‌اند؛ این فایل‌ها را به جای قالب اصلی روی پنل نصب نکنید.

## گرفتن شات واقعی برای README

تصویر `screenshots/preview-purple.svg` فقط معرفی پالت با دادهٔ نمونه است، نه اسکرین‌شات مرورگر. محیط آماده‌سازی بسته امکان ثبت شات مرورگر را نداشت. ابزار زیر صفحهٔ واقعی ساخته‌شده از قالب را در اندازهٔ موبایل و دسکتاپ باز و ثبت می‌کند؛ عکس‌ها حاوی توکن واقعی نیستند و ماوس در تصویر نمی‌آید.

در پوشهٔ پروژه و **داخل PowerShell ویندوز**، با Python نصب‌شده:

```powershell
py -m venv .preview-venv
.\.preview-venv\Scripts\python.exe -m pip install playwright
.\.preview-venv\Scripts\python.exe -m playwright install chromium
.\.preview-venv\Scripts\python.exe scripts/capture_previews.py
```

فعال‌سازی محیط مجازی لازم نیست. برای Linux به‌جای `py` از `python3` و به‌جای مسیر `Scripts/python.exe` از `.preview-venv/bin/python` استفاده کنید. مرورگر ممکن است به پیش‌نیازهای سیستم‌عامل Playwright نیاز داشته باشد.

خروجی‌ها:

- `screenshots/preview-purple.jpg`: شات کامل موبایل، عرض ۳۹۰ پیکسل.
- `screenshots/preview-purple-desktop.jpg`: شات کامل دسکتاپ، عرض ۱۴۴۰ پیکسل.
- پس از ثبت موفق هر دو تصویر، لینک تصویر بنفش در README به شات موبایل تغییر می‌کند.

عکس‌ها را قبل از انتشار نگاه کنید. پارامتر اختیاری `--panel marzban` یا `--panel pasarguard` شات همان پنل را می‌گیرد. اطلاعات تصاویر نمونه‌اند؛ این ابزار تست سرویس یا نصب واقعی پنل نیست.

## بررسی کد

```bash
python3 -m unittest discover -s scripts -p 'test_*.py'
python3 scripts/build_preview.py
node scripts/test_themes.cjs
```

تست رنگ‌ها شروع با هر رنگ، دو دور تعویض کامل، گرادیان و رنگ مرورگر را روی هر سه قالب بررسی می‌کند. حفظ تنظیمات و manifest بنفش هم در تست‌های نصاب بررسی می‌شود.
