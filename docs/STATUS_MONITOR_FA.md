## ورود خودکار مقصدها

گزینهٔ۴ منو اکنون حالت پیش‌فرض خودکار دارد: یک لینک ساب کامل و خصوصی را روی همان سرور وارد کنید. VLESS/Trojan/VMess/Shadowsocks خام/Base64 و HTML Ghost Sub خوانده می‌شوند؛ فهرست تا ۶۴ مقصد TCP هر ۱۵ دقیقه تازه می‌شود. پایش هر ۶۰ ثانیه است. تنظیم reverse proxy خروجی هنوز جدا است. حالت دستی زیر همچنان قابل استفاده است.

# پایش دسترسی سرورها — نسخهٔ آزمایشی Ghost Sub

این بخش از Usage Tracker مستقل است. monitor.py فقط اتصال TCP به host/port های از پیش تعیین‌شدهٔ مدیر را بررسی می‌کند؛ هیچ درخواست مرورگر نمی‌تواند هدف تازه بسازد یا اسکن شروع کند.

## معنی عددها

- «قابل دسترس»: بررسی‌های اخیر موفق بوده‌اند.
- «ناپایدار»: در حداکثر سه نمونهٔ اخیر، موفقیت و خطا دیده شده یا هنوز سه خطای متوالی کامل نداریم.
- «پاسخ نداده»: سه نمونهٔ اخیر متوالی ناموفق بوده‌اند.
- «نامشخص»: داده وجود ندارد،داده قدیمی شده، feed دریافت نشده یا قالب کانفیگ قابل نگاشت نیست.
- درصد،نسبت نمونه‌های موفق در بازهٔ حداکثر۲۴ساعت گذشته است؛ درصد زمان پیوسته و آپ‌تایم سیستم‌عامل نیست. تعداد نمونه و مدت مشاهده کنار آن می‌آید.
- بخش بدون نمونه در تاریخچه خالی است؛ از زمان نصب به عقب داده ساخته نمی‌شود. شروع سرویس با یک نمونه،تاریخچهٔ۲۴ساعته ایجاد نمی‌کند.
- این آزمون DNS/TCP را از محل سرور پایش می‌سنجد؛ نه اتصال واقعی VLESS/VMess/Trojan/SS ،نه اعتبار حساب و نه سلامت از دید همهٔ اپراتورها. latency ذخیره‌شده زمان connect از محل پایش است،نه پینگ کاربر.
- برای بررسی از دید ایران،یک پایشگر داخل ایران لازم است. در این نسخه هر feed نمای یک نقطهٔ پایش را دارد؛ تجمیع چند نقطه پیاده نشده است.

## تنظیم اهداف

status-monitor/config.example.json را در مسیر خصوصی خارج از webroot کپی و ویرایش کنید. هر host و port باید دقیقاً همان آدرسی باشد که در لینک کانفیگ به کاربر داده می‌شود؛ alias های متفاوت DNS کلید یکسان تولید نمی‌کنند. country یک کد دوحرفی صریح مثل DE یا PL است؛ براساس IP ،کشور حدس زده نمی‌شود.
فهرست اهداف را فقط برای زیرساخت مجاز خودتان وارد کنید. این تنظیمات هیچ رمز پنل یا UUID کاربر نیاز ندارد.

نگاشت فعلی frontend شامل VLESS ، Trojan ، VMess و SS با host/port مشخص است. قالب یاپروتکل ناشناخته وضعیت نامشخص می‌گیرد. IP مخفی یاعدم نمایش کشور باعثحدس‌زدن نمی‌شود.

## اجرای آزمایشی بدون نصب

```bash
python3 -I status-monitor/monitor.py --config /PRIVATE/PATH/config.json --state-dir /PRIVATE/PATH/status-state --once
```

این فرمان واقعاً اهداف تنظیم‌شده را بررسی می‌کند. ورودی نمونه را بدون جایگزین‌کردن YOUR_NODE_HOST اجرا نکنید.
حالت پیوسته بدون --once ، JSON را فقط روی 127.0.0.1 و پورت تنظیم‌شده ارائه می‌دهد؛مسیر HTTP فقط /status.json است. --output مسیرخروجی JSON اختیاری است،ولی وجودفایلکنارقالب،به‌تنهایی به‌معنی قابل‌دریافت‌بودنش ازوب نیست.

## نصب اختیاری سرویس

ازبستهٔکامل روی میزبان مناسب،پس ازویرایش config:

```bash
sudo bash status-monitor/install.sh /PRIVATE/PATH/config.json
```

نصاب config را اعتبارسنجی می‌کند،حساب محدود ghost-status وفایل‌های monitor/unit را می‌سازد؛هیچ probe/start/restart/enable انجامنمی‌دهد. config قبلی رانگه می‌دارد. نصب مجددباینری به‌معنیارتقایپردازشزنده نیست؛ restart بایدانتخابی باشد.

پس ازمرور config ،شروع وبوت انتخاب‌هایصریح‌اند:

```bash
sudo systemctl start ghost-status.service
sudo systemctl enable ghost-status.service
```

اینفرمان‌ها سرویس monitor راکنترل می‌کنند،نهپنل یاتونل.

## اتصال بهقالب

در reverseproxyHTTPS موجود خودتان یک route فقطخواندنیبرای JSON بسازید؛مثال برای Nginx رویهمانمیزبان monitor:

```nginx
location = /ghost-status.json {
    proxy_pass http://127.0.0.1:19191/status.json;
    proxy_set_header Host localhost;
    add_header Cache-Control "no-store" always;
}
```

این قطعه نمونهٔ route است،نه فایلکامل Nginx. مسیرروی origin صفحهٔساب باشد،پیش از reload پیکربندی راچککنید و route هایپنل راجایگزین نکنید. اگر proxy داخل container است، 127.0.0.1 آدرسهمان container است؛آدرس‌دهی بایدباتوپولوژیواقعی بررسیشود. هیچ proxy/firewall به‌صورتخودکارنصب یاتغییر داده نشده.

درمنوی install.sh صفحه، Status feed را /ghost-status.json واردکنید. Enter انتخابذخیره‌شده رانگه می‌دارد؛ off غیرفعالشمی‌کند. URL خارجی HTTPS فقطباقانون CORS مناسبدر origin مربوطکارمی‌کند؛ monitor پیش‌فرض CORS عمومیندارد. ازلینکحاویرمزیا token استفادهنکنید.
Feed فقطشناسهٔمشتق‌شدهٔ endpoint ونتیجهٔنمونه‌هاراارائه می‌کند،نه host/port/credential خام. شناسه‌هااحراز هویتنیستند؛ feed عمومیمی‌تواندوجودگره‌هاوالگویقطعی‌ها رانشان دهد،پسفقطنتایجیراارائهکنیدکهقصدانتشارشانرادارید.
پورت loopbackmonitor رابه‌صورتعمومی bind نکنید. رکوردهای SQLite و config خصوصی بمانند.

## ظاهر

پرچم‌ها ونشان‌هایوضعیت SVG محلی باقابوبافتیکدست‌اند،نه emoji خام،فونتایموجییا customemoji تلگرام. گرافیک اصلی کشورهاییمثل DE ، PL ، NL ، FR ، GB ، US ، TR ، FI ، SE ، CA ، AE ، IR ، RU داخلکداست؛کشورناشناخته باکرهٔزمیننمایشداده می‌شود. ایننسخههمهٔپرچم‌هایجهانراندارد.
اگرنامکانفیگپرچمایموجیداشتهباشد،براینمایشبهپرچم SVG تبدیل می‌شود ودرنامتکرارنمی‌شود؛لینکاصلیبرای copy/import تغییرنمی‌کند.
پیش‌نمایش HTML عمداًدادهٔنمونهومشخص‌شدهٔ DEMO دارد؛برایاستقرارواقعیقالب‌ها فاقد status ساختگی‌اند.
